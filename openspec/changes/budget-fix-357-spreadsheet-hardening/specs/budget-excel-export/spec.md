## ADDED Requirements

### Requirement: Untrusted text is never exported as a formula
Every value in an exported workbook that comes from user or tenant input SHALL be stored as a text cell. This covers budget, organisation, donor and project names, category names, line and expense descriptions, `extra_fields` keys and values, and user names in the audit footer. It applies on every sheet, whatever the value's leading character (`=`, `+`, `-`, `@`). Formulas generated by the application SHALL remain formulas.

#### Scenario: Description that looks like a formula
- **WHEN** a budget line's description is `=HYPERLINK("https://evil.example","x")` and the budget is exported
- **THEN** after saving and reloading the workbook, that cell has text type and its value is exactly the original string

#### Scenario: Extra field key that looks like a formula
- **WHEN** a line has an `extra_fields` key `=1+1` and the budget is exported
- **THEN** the corresponding header cell is text with value `=1+1`

#### Scenario: Generated totals still calculate
- **WHEN** a budget containing formula-like descriptions is exported
- **THEN** the category subtotal, grand total, conversion and cross-sheet actuals cells are still formulas referencing the expected cells
