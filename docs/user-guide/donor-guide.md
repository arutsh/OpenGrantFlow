# For Donors & Funders

> Part of the [Open Grant Flow User Guide](./README.md) · See also: [NGO / Grantee Guide](./ngo-guide.md)

This guide covers the workflow for an organisation funding one or more grantees through Open Grant Flow.

## 1. Approving grantees

Before you can see a grantee's budgets, you need to link to them. Go to **Settings → Manage Grantees**, search for the NGO by name, and approve them. Approved grantees can be revoked later if the relationship ends. This is a deliberate, explicit step — nothing is shared with you automatically just because an NGO exists on the platform.

## 2. Your dashboard

The Donor dashboard gives you portfolio-level visibility across everyone you fund:

- **Total allocated, by currency** — Shown per currency, never blended together, so a mixed-currency portfolio is never misrepresented as one number.
- **Grantees** — Every approved grantee organisation, with their total committed amount and number of budgets.
- **Funded budgets** — Every confirmed budget you fund, with the amount in your own currency alongside the real local total and the exchange rate used to get there — so the conversion is never opaque.

From the Funded Budgets table you can jump straight into a grantee's budget or their reports. From a budget's own detail view, you can also export it as a formatted Excel workbook — see the NGO guide's [Exporting to Excel](./ngo-guide.md#7-exporting-to-excel) for what each sheet contains.

## 3. Confirming a budget

Either party can confirm a budget once it's ready — you, as the matching funder, can set the start date and confirm it yourself, which is useful when you want to lock in the agreement without waiting on the grantee to do it.

## 4. Reviewing reports

When a grantee submits a report, it's ready for your review. Open the report to see each line item against its budget line, expense date, and attached evidence (receipts, invoices, proof of payment). From there you can:

- **Approve** — Accept the report as submitted.
- **Reject** — Send it back with review notes explaining what's missing or incorrect. The grantee then explicitly reopens it to move it back to Draft so they can fix it and resubmit.

> **Note:** If a budget has no funder explicitly linked to it, the grantee's own organisation can approve/reject its reports instead, so review is never blocked by a missing configuration.
